Accounts: View shows the summary table. Create adds accounts, Edit changes any cell in the Excel-format grid, Delete removes accounts. Anyone with Create, Edit or Delete on Accounts also sees the full Excel-format grid. EMAIL/SMS generator: View opens the generator page (and lets the user generate), Edit lets the user change the shared email / SMS templates and the Text button message (EMAIL/SMS Generator → Templates). Contact Directory: View shows customer, contract number, phone number, email and contact person; Edit lets the user update phone, email and contact person. All of this is enforced on the server.
